# CREDO model architecture

The CREDO model comprises reliability-aware foundation model aggregation (RAFMA), bidirectional cross-modal attention, context-aware reliability-guided evidence reorientation (CARER), and multi-opinion consistency regularization (MCR).

The model interface used by the training workflow is `src.models.dca_moe_shared_clens_confidence_routed_v2`.

For conceptual details, refer to the [project README](../../README.md) and [framework figure](../../assets/fig_framework.pdf).
