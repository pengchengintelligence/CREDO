# CREDO model components

CREDO comprises reliability-aware foundation model aggregation (RAFMA), bidirectional cross-modal attention, context-aware reliability-guided evidence reorientation (CARER), and multi-opinion consistency regularization (MCR).

The full implementation and additional reproducibility resources will be released after the paper is accepted. See the [project README](../../README.md) for a description of the framework and currently available supporting files.
